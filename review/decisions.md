# Решения по проекту maxzhitnik-site

## 2026-10-17 — Источник видео для hero-ленты

### Проблема
YouTube (видео `znoFm5Oy4S8` и `Nt90WcHys88`) заблокировал скачивание через yt-dlp.

Причина: YouTube внедрил механизм **SABR (Server-side Ad Bypass Resistance)** — все HLS-фрагменты возвращают HTTP 403, формат `18` (прямой https) тоже отдаёт 403. Попытки через разные клиенты (tv, ios, android, mweb, web_creator) и с cookies из Chrome не дали результата. PO Token для обхода не был получен.

### Принятое решение
Клипы `clip_1.mp4` — `clip_7.mp4` созданы из существующих фотографий тренинга с помощью ffmpeg (статичный кадр 3 секунды):

| Клип | Источник | Эффект |
|------|----------|--------|
| clip_1.mp4 | group-CHPK3272.jpg | серый |
| clip_2.mp4 | __352.jpg | серый |
| clip_3.mp4 | IMG_7163.jpg | серый |
| clip_4.mp4 | IKZ10140.jpg | **цветной** (центральная карточка) |
| clip_5.mp4 | group-CHPK3183.jpg | серый |
| clip_6.mp4 | 2B3A9543.jpg | серый |
| clip_7.mp4 | group-CHPK2995.jpg | серый |

Аватарки `av1.jpg` и `av2.jpg` взяты из уже имеющихся превью `assets/reviews/*.jpg`.

### Как заменить на реальные видео с YouTube
Если нужны настоящие видеоклипы:
1. Скачать видео вручную в браузере через расширение (например, Video DownloadHelper в Firefox)
2. Сохранить как `raw_znoFm5Oy4S8.mp4` и `raw_Nt90WcHys88.mp4` в папку `assets/video/`
3. Запустить ffmpeg-нарезку по командам из задачи
4. YouTube SABR-ограничение — проблема уровня сессии браузера, обойти с сервера нельзя без PO Token
