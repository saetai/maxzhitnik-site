## Как заменить на живые ролики

Положить исходники с тренинга и нарезать тем же форматом, имена оставить `clip-N.mp4` / `clip-N.jpg` — код менять не нужно:

```
ffmpeg -ss <сек> -t 4 -i in.mp4 -vf "scale=480:-2,format=gray" -an -c:v libx264 -crf 28 -movflags +faststart assets/hero/clip-N.mp4
ffmpeg -ss 0 -i assets/hero/clip-N.mp4 -frames:v 1 -q:v 4 assets/hero/clip-N.jpg
```
